1. SYSTEM REQUIREMENTS
================================================================================

Minimum Requirements:
--------------------
- Operating System: Windows 10/11, macOS 10.15+, or Linux (Ubuntu 20.04+)
- Python: 3.8 or higher
- RAM: 4GB minimum (8GB recommended)
- Storage: 1GB free space
- Internet: Required for email notifications

Recommended Production Environment:
-----------------------------------
- Ubuntu 22.04 LTS
- PostgreSQL 14+
- Nginx
- Gunicorn
- SSL Certificate (Let's Encrypt)

3. STEP-BY-STEP SETUP
================================================================================

3.1: Clone Repository
----------------------
git clone https://github.com/yourusername/invoice-system.git
cd invoice-system

3.2: Create Virtual Environment
-------------------------------
# Windows:
python -m venv venv
venv\Scripts\activate

# macOS/Linux:
python3 -m venv venv
source venv/bin/activate

3.3: Install Dependencies
-------------------------
pip install --upgrade pip
pip install -r requirements.txt

3.4: Create .env File
---------------------
Create a file named .env in the project root with:

# Security
SECRET_KEY=your-super-secret-key-change-in-production
SERVER_NAME=localhost:5000

# Database (SQLite for development)
# DATABASE_URL=sqlite:///instance/invoice_system.db

# Email Configuration
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587
MAIL_USE_TLS=True
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_DEFAULT_SENDER=your-email@gmail.com

# Application
APP_NAME=Invoice System
APP_VERSION=1.0.0
LOG_LEVEL=INFO

# Security (set to False for development)
PREFERRED_URL_SCHEME=http
SESSION_COOKIE_SECURE=False
REMEMBER_COOKIE_SECURE=False

3.5: Initialize Database
------------------------
python
>>> from app import create_app
>>> from app.extensions import db
>>> app = create_app('development')
>>> with app.app_context():
...     db.create_all()
...     print("Database created successfully!")
...     exit()

3.6: Run the Application
------------------------
python run.py

3.7: Access the Application
---------------------------
Open browser: http://localhost:5000
Login: admin@invoicesystem.com
OTP: Check your email for the verification code

4. DATABASE CONFIGURATION
================================================================================

4.1: SQLite (Development - Default)
------------------------------------
No additional setup required. Database will be created at:
instance/invoice_system.db

4.2: PostgreSQL (Production - Recommended)
-------------------------------------------
# Step 1: Install PostgreSQL
# Ubuntu/Debian:
sudo apt update
sudo apt install postgresql postgresql-contrib

# macOS:
brew install postgresql
brew services start postgresql

# Windows:
# Download from: https://www.postgresql.org/download/windows/

# Step 2: Create Database and User
sudo -u postgres psql

CREATE DATABASE invoice_db;
CREATE USER invoice_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE invoice_db TO invoice_user;
\q

# Step 3: Update .env
DATABASE_URL=postgresql://invoice_user:your_secure_password@localhost:5432/invoice_db

# Step 4: Install PostgreSQL driver
pip install psycopg2-binary

# Step 5: Run migrations
flask db upgrade

4.3: MySQL (Alternative)
------------------------
# Step 1: Create database
CREATE DATABASE invoice_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'invoice_user'@'localhost' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON invoice_db.* TO 'invoice_user'@'localhost';
FLUSH PRIVILEGES;

# Step 2: Update .env
DATABASE_URL=mysql+pymysql://invoice_user:your_secure_password@localhost/invoice_db

# Step 3: Install driver
pip install pymysql

7. PRODUCTION DEPLOYMENT
================================================================================

7.1: Nginx Configuration
------------------------
# /etc/nginx/sites-available/invoice-system

server {
    listen 80;
    server_name yourdomain.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com;

    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /static/ {
        alias /path/to/your/app/static/;
        expires 30d;
    }
}

7.2: Systemd Service
--------------------
# /etc/systemd/system/invoice-system.service

[Unit]
Description=Invoice System Gunicorn Service
After=network.target

[Service]
User=www-data
Group=www-data
WorkingDirectory=/path/to/your/app
Environment="PATH=/path/to/venv/bin"
Environment="FLASK_ENV=production"
ExecStart=/path/to/venv/bin/gunicorn -w 4 -b 127.0.0.1:8000 wsgi:app
Restart=always

[Install]
WantedBy=multi-user.target

# Enable and start:
sudo systemctl enable invoice-system
sudo systemctl start invoice-system

8. TROUBLESHOOTING
================================================================================

8.1: Database Connection Errors
--------------------------------
Error: "Can't connect to PostgreSQL server"
Solution:
# Check if PostgreSQL is running
sudo systemctl status postgresql
# Start PostgreSQL
sudo systemctl start postgresql
# Check connection
psql -U your_user -d your_db -h localhost

Error: "Table doesn't exist"
Solution:
# Run migrations
flask db upgrade
# Or create tables
flask shell
>>> from app import create_app
>>> from app.extensions import db
>>> app = create_app('production')
>>> with app.app_context():
...     db.create_all()

8.2: Email Errors
------------------
Error: "535 Authentication failed"
Solution:
# For Gmail: Use App Password, not regular password
# For other SMTP: Verify username/password

Error: "Connection refused"
Solution:
# Check SMTP server and port
# Try: telnet smtp.gmail.com 587

8.3: Module Not Found Errors
----------------------------
Error: "ModuleNotFoundError: No module named 'psycopg2'"
Solution:
pip install psycopg2-binary

Error: "ModuleNotFoundError: No module named 'flask'"
Solution:
# Activate virtual environment
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows
# Install requirements
pip install -r requirements.txt

8.4: Application Errors
------------------------
Error: "Secret key must be set"
Solution:
# Add SECRET_KEY to .env

Error: "Server Error 500"
Solution:
# Check logs
tail -f logs/app.log
# Check for missing environment variables
# Verify database connection

8.5: Common Issues
------------------
Issue: Can't login
Solution:
# Check if OTP email is being sent
# Check email spam folder
# Verify user exists in database

Issue: Scheduler not working
Solution:
# Check logs for scheduler errors
# Verify auto-submit day in System Settings
# Manual trigger: http://localhost:5000/admin/force-auto-submit
